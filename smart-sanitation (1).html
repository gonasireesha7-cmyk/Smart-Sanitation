This prototype sends reports using WhatsApp's click-to-chat link, so no server or paid API is needed for the demo — the user's own WhatsApp opens with the report pre-filled, ready to send to the facility number above. For production, this same trigger can call the WhatsApp Business Cloud API server-side to log every report automatically without the user tapping send, and to route it into a dashboard.
